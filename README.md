 🚀 BrainVault

BrainVault is a modern Student Management System built using JSP, Servlets, JDBC, MySQL, and Bootstrap.
 ✨ Features

- 🔐 Login & Signup Authentication
- 👨‍💼 Admin Dashboard
- 🎓 Student Dashboard
- ➕ Add Students
- ✏️ Update Students
- ❌ Delete Students
- 🔍 Search Students
- 📊 Interactive UI
- 🔒 Role-based Access Control

---
 🛠️ Tech Stack

- Java
- JSP & Servlet
- JDBC
- MySQL
- Bootstrap 5
- HTML/CSS/JavaScript

---

---
 ⚙️ How to Run

1. Clone repository
2. Import into VS Code / Eclipse
3. Configure MySQL database
4. Run Tomcat Server
5. Open:
   http://localhost:8080/BrainVault-1.0/
